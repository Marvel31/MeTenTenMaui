## 📱 안드로이드 APK

**파일명**: `MeTenTen-v1.0.0-Android.apk`  
**크기**: 약 29MB  
**최소 안드로이드 버전**: Android 7.0 (API 24) 이상

### 설치 방법

1. APK 파일을 안드로이드 기기로 전송
2. 파일 관리자에서 APK 파일 클릭
3. "출처를 알 수 없는 앱" 설치 허용 (필요 시)
4. 설치 진행

### 권한 안내

앱 실행 시 다음 권한을 요청합니다:
- 📂 파일 저장/읽기: 10&10 데이터를 내보내고 불러오기 위함
- 🌐 인터넷: (필요 시 향후 기능)

## 💻 Windows 앱

**파일명**: `MeTenTen-v1.0.0-Windows-x64.zip`  
**크기**: 약 45MB  
**지원 OS**: Windows 10 버전 17763 이상 (October 2018 Update)

### 설치 방법

1. ZIP 파일 압축 해제
2. 압축 해제된 폴더에서 `MeTenTenMaui.exe` 실행
3. 별도 설치 과정 불필요

### 시스템 요구사항

- Windows 10 (빌드 17763) 이상
- .NET 9.0 Runtime (Framework-dependent 빌드의 경우)
  - 자동으로 다운로드 안내 메시지 표시됨

### 참고사항

- 앱 데이터는 로컬 AppData 폴더에 저장됩니다
- 처음 실행 시 Windows Defender SmartScreen 경고가 표시될 수 있습니다
  - "추가 정보" → "실행" 클릭하여 진행

## 🚀 주요 기능

1. **10&10 주제 관리**: 부부 대화 주제 작성 및 관리
2. **느낌 표현 예시**: 65개 이상의 감정 표현 예시 제공
3. **주요 기도문**: 가톨릭 공식 기도문 6개 수록
4. **파트너 대화**: 부부 관계 개선을 위한 가이드
5. **데이터 내보내기/불러오기**: 월별 데이터 백업 및 복원

---

## 📝 사용 안내

### 10&10 작성하기

1. "10&10" 메뉴 선택
2. "새 주제 추가" 버튼 클릭
3. 주제 입력 후 저장
4. 주제 선택 후 "10&10 작성" 클릭
5. 10분 타이머를 사용하여 마음을 작성
6. 작성 완료 후 저장

### 데이터 관리

- **내보내기**: 설정 아이콘(⚙️) → 내보내기 → 월별 데이터 저장
- **불러오기**: 설정 아이콘(⚙️) → 불러오기 → 파일 선택 → 병합 옵션 선택

## 🆘 문제 해결

### 안드로이드

**설치가 안 됩니다**
- 설정 → 보안 → "출처를 알 수 없는 앱" 허용

**앱이 실행되지 않습니다**
- 안드로이드 버전 확인 (7.0 이상 필요)
- 앱 삭제 후 재설치

### Windows

**실행 시 .NET이 필요하다는 메시지가 나옵니다**
- .NET 9.0 Runtime 다운로드: https://dotnet.microsoft.com/download

**Windows Defender가 차단합니다**
- "추가 정보" 클릭 → "실행" 버튼 클릭
